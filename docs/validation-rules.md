# Validation rules

Validation is deterministic and runs against the structured document. The current Procedure rules require a title, purpose, at least one procedure section, section titles, and at least one nonempty step per section. Structured decisions require both IF and THEN unless their source was preserved as an unsplit imported decision.

Required fields are explicitly marked in the editor and validated from the structured document. Additional template-field classifications will be added only when they have defined editor or validation behavior. Validation must never infer a writing-quality requirement.
