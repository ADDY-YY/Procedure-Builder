# Release checklist

- Run `npm test` and `npm run build`.
- Create each configured document type and verify its required/optional behavior.
- Test autosave, manual save, reopen, duplicate, delete confirmation, recovery, and project backup.
- Test procedure sections, steps, substeps, decisions, important information, images, and reordering.
- Compare preview and each available export with the approved template.
- Test import preservation, malformed input, and unmapped-content review.
- Test keyboard navigation, screen readers, zoom, current Chrome, and current Edge.
- Confirm documentation and template configuration were updated with the same change.
