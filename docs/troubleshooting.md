# Troubleshooting

If drafts do not appear, confirm the browser is using the same profile and origin. Browser privacy tools, storage limits, or clearing site data can remove local drafts. Download a project backup for important work.

If an imported document has content in the review section, it was preserved because it did not map deterministically to the current configuration. Review it before publishing; do not remove it without an author decision.

If a preview differs from an approved template, do not make a local styling workaround. Update the documented template rendering configuration and verify every output from the same structured document.
